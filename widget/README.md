# messaging-ai widget

Standalone embeddable chat widget for messaging-ai. Single-script embed,
Shadow-DOM-isolated, Preact + Vite library build.

## Embed (planned, post-integration)

```html
<script
  src="https://app.messaging-ai.com/widget/v1/widget.js"
  data-tenant="acme"
  data-position="bottom-right"
  async
></script>
```

## Develop

This package is a workspace under the root `messaging-ai` repo. From the repo root:

```bash
npm install                # installs root + widget deps
npm run widget:dev         # vite dev server with the dev shell at /
npm run widget:build       # production build + bundle-size guard
```

Or from inside `widget/`:

```bash
npm run dev
npm run build
npm run check:size         # standalone bundle-size check
```

## Bundle budget

- Hard limit: **25 KB gz** — `npm run build` exits non-zero above this.
- Stretch:   **20 KB gz** — emits a warning above this.
- Composition (preact / widget src / styles) reported in the build output.

## Architecture (planned)

- **Framework:** Preact + `preact/hooks` (~4 KB gz).
- **Style isolation:** Shadow DOM with constructed stylesheet — host page CSS cannot reach in, widget CSS cannot leak out.
- **Tokens:** generated by `scripts/generate-widget-tokens.mjs` at the repo root from `src/lib/design-tokens.ts`. Do not edit `widget/src/tokens.ts` by hand. (Lands in commit 2.)
- **Wire protocol** (locked, integration commit): `POST /api/widget/messages` with body `{ tenantSlug, conversationId?, message, customerExternalId }`, response is `text/event-stream`-shaped chunks over a single HTTP response. Two event types: `delta` (text fragments) and `done` (final structured payload).
